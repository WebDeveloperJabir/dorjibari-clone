# Dorjibari Website Clone

This is a clone website of the original **Dorjibari** ([dorjibari.com.bd](dorjibari.com.bd)). I cloned that for practical purposes. Though I didn't complete the whole clone, I have learnt many things from it.

**Project Deployed on:** Cloudfare ([cloudfare.com](cloudfare.com))  
**Project Link:** [https://dorjibari-clone.jabir-webdev.workers.dev](https://dorjibari-clone.jabir-webdev.workers.dev)

I didn't used any third-party tool or didn't copied their codes to clone it. Instead, I created this from scratch. I tried to design the exact. It is the proof that I can design a web pixel-perfect by seeing the original. Also, all the functionalities of the website is also written by me. For working on it, I have learnt many things such as advanced responsive design, optimizations, dealing with 1000+ lines of CSS code, dynamic pages by JS etc. Really, I have learned so many things from this project.

## Why I stopped it

Because I started it cloning without building the foundation first. I didn't declared universal typography, colors, spacing, styles for elements etc rules. For that, when the website started growing, I have faced much problems and I end up with thousands of lines of CSS codes. A section became dependant to another. No shared rules, repetetive styles, no universal color, every elements styled individually etc. So, for that, I decided to stop the project here. But that's not all. I have learned so much things from it. And as it was my life's first big project cloning from scratch, it is normal to do these mistakes. I will take lessons from them.

## Key Learnings

- Replicating styles through visual inspection rather than copying code.
- Achieving mastery-level responsive layouts.
- Building functional modals and widgets using vanilla JavaScript.
- Programming custom image sliders from scratch.
- Optimizing SVG code using tools like [SVGOMG](https://svgomg.net).
- Designing premium navigation bars.
- Developing advanced product cards.
- Integrating CSS variables with CSS Grid, dynamically overridden by JavaScript to optimize layout adjustments.
- Executing advanced DOM manipulation and logical scripting.

## Core Lessons

- Establish a solid foundation (shared styles, CSS variables, etc.) before cloning a site; a weak base causes larger structures to fail.
- Prioritize reusable classes and shared styles.
- Maintain loose coupling by ensuring individual sections remain completely independent.
